# רונן משלם 💸

אתר בדיחה בסגנון אפליקציית משלוחים, שבו אפשר להזמין אוכל ו"רונן משלם" על הכול.

## קבצים בריפו

- `index.html` — קובץ האתר הראשי
- `logo.png` — לוגו האתר
- `banner.png` — באנר עליון

## איך מעלים ל-GitHub

1. צור ריפו חדש ב-GitHub
2. העלה את הקבצים:
   - `index.html`
   - `logo.png`
   - `banner.png`
3. ודא שהקובץ הראשי נקרא בדיוק `index.html`

## איך לפרוס ל-GitHub Pages

1. כנס לריפו ב-GitHub
2. פתח `Settings`
3. בתפריט הצד פתח `Pages`
4. תחת **Build and deployment** בחר:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. שמור את ההגדרות
6. המתן כמה דקות עד שהאתר יתפרסם

## כתובת האתר

אם שם הריפו הוא:

`ronen-meshalem`

והיוזר שלך הוא:

`YOUR-USERNAME`

אז כתובת האתר תהיה:

`https://YOUR-USERNAME.github.io/ronen-meshalem/`

## הערות

- אם האתר לא עולה, בדוק ש-`index.html` נמצא בשורש הריפו
- אם התמונות לא מופיעות, בדוק ש-`logo.png` ו-`banner.png` נמצאים באותה תיקייה כמו `index.html`
